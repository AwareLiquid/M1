## 1. 目的

8/31 批次（9/12 臂，见 commit 1ed4625）发现 stage B 对部分种子发散
（1:4 s2 两次独立 = NaN / 714.9；1:2 系统性 1365 / 16136），种子方差
跨三个数量级 → 单 seed 过门不可引用。本确认跑在稳定化配方下重出
**可引用**的比例-质量判读。

## 2. 稳定化（相对 8/31 配方的唯一变更）

- `--warmup_b 200`（stage B 线性 warmup，占 steps_b=2000 的 10%）—
  机制：缓和 stage A→B 目标切换冲击，防 AdamW 二阶矩在最初几步被毒化；
- grad clip 1.0 **已在位**（opt_apply，8/30 起就有——8/31 的发散是
  clip 也拦不住的持续劣化，故加 warmup 而非加 clip）；
- 其余全部不动：steps_a=1000 / steps_b=2000 / seq 512 / batch 1 /
  grad_accum 4 / lr 5e-4 / d_proto 96 / proj_rank 384 / fw_dim 96。

## 3. 臂与种子

- 全曲线：4 比例 × 6 seeds = 24 臂（推荐——曲线完整，PR #2 一步到位）；
- 最小可引用：1:4 + 0 × 6 seeds = 12 臂（额度紧张时的降级选项）；
- 设备：**单一设备族**（T4 fp16 或 A100 bf16 二选一，整条不混 — 红线 R1）。

## 4. 发散处理规则（预注册，二选一后冻结）

- **规则 R-rerun（推荐）**：每臂发散允许重跑 1 次；重跑仍发散则该种子
  记"发散"，均值只计有效种子，有效种子 <3 时该比例判读=不可引用；
- 规则 R-strict：发散臂直接计入均值（PPL 取实际值或上限 1000）——
  最保守，1:4 大概率判负；
- 禁止：按结果挑选种子、剔除后不声明、事后更换规则。

## 5. 判据（与 8/29 预注册一致，不移动）

- 门：**1:4 的 PPL 改善 ≥15%**（6 seeds 均值，对照 = 同批 ratio-0）；
- PASS → 补 BENCHMARKS/RESULTS 正表（可引用），PR #2 闭环；
- FAIL → 如实记"回填无效"负结果，线关闭或降级为开放问题。
