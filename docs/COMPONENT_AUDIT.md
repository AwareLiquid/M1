# 液态与类脑组件审计：归属、证据及决策

日期：2026-09-09。Owner：Everest。
审计基线：M1 c3f3008；M2 8409311。本文完成本轮历史组件族的分类，
不等于复现所有训练。覆盖可访问 Git 历史、主要结果工件、接口与训练接线；
未入库的服务器日志、权重和不可访问历史不在已核验范围。

## 研究方向决定

创新主体是液态状态转移、预测误差反馈、可更新记忆和离线学习。
不把增加注意力层、堆参数或降低单一PPL当作液态创新本身。
Transformer是强对照和兼容桥接，不是必须复制的目标；归一化等通用工程可复用。
新机制必须在适合它的任务上验证，不以LM辅助损失无收益否定所有类脑用途。
同时，生物命名、信号变化、单元测试通过均不等于任务收益。

## 证据等级

- E1：接口/梯度/数值性质测试或架构钩子；未证明任务收益。
- E2：有限任务、预算或种子的实验信号；只在限定范围使用。
- E3：已有多种子任务证据；仍不代表跨域、规模化或因果归因全部成立。
- N：在已测协议下不支持或有负面结果；不是数学上的永久不可能。
- U：未找到完整训练证据/原始工件。未测与判负严格分开。

## 必须修正的旧解释（备注，不静默改写原始结果）

1. O1 switch-matrix是48M、单seed、1200步；只支持当前预算不推广，不足以永久否定五类机制。
2. “融合核toy有效、adapter LM无效，所以唯一原因是接入位置”不是已证因果；任务/规模/训练也不同。
3. parity的约8倍长度经验不能直接推出语言模型32K能力或恒定总内存。
4. 物理基准比较Hamiltonian+Verlet与MLP+Euler，网络和积分器同时变化，不能全部归功于液态。
   辛积分也不意味着任意步长下能量严格守恒；测试证明特定设置下较低漂移。
5. BENCHMARKS旧文说物理头未接入model.py，但当前有可选HamiltonianWorldModelHead。
   “可选接线存在”与“物理基准训练/收益不属于LM”可同时成立；用户决定其归Physics。
6. fast_weight_core显式时间外积累积具有训练内存代价，不能当作已经实现的常量状态解码。
7. 未发现优秀整套架构被误删的充分证据。已确认的是默认/入口漂移、遗漏同步和不同实现混称。

## 有限研发队列（决定，不是已实现功能）

优先一：M1持久记忆工程保持可用；M2研究融合式液态预测反馈＋生成式重放。
优先二：M2选择性状态转移和显式可更新记忆；先正确性、学习性再扩大任务。
优先三：目标反馈与有限工作区，只有前两条需要它们时才接入。
暂停：多神经调制总线、全模块拼装、旧循环原样重跑、2B直接大训。
Physics：另线保留头和基准，确认目标仓库后再迁移；本轮不移动任何源码。

共同验证：无机制/简单机制/液态机制对照；固定任务、参数、训练数据与计算预算；
按任务报告记忆更新、长期误差、遗忘、适应速度、时延/能耗，不仅看PPL。
先预注册可学性和停止条件；历史可复用结果不重训。创新允许失败，不允许归因混淆。
