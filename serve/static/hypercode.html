FAQ

HyperCode 和 HyperWork 是什么关系?

同一个产品、同一个大脑。HyperCode 是产品总名,HyperWork 是它的工作助手模式 —— 写代码用它,做估值、审合同、写论文也用同一个它。记忆与配置完全共享。

需要 VPN 或海外信用卡吗?

不需要。HyperCode 面向中国大陆开发者设计,所有依赖国内可达。算力默认接入国产 DeepSeek 模型,一个 API key 全体代理共用。

一个任务能连续跑多久?

当前版本支持数小时的自主任务:检查点保证崩溃不重来,后台压缩保证上下文不退化。我们持续把"连续工作时长"作为核心指标打磨。

内置技能怎么触发?

无需记忆命令。你用中文或英文描述需求(如"帮我做一份融资 PPT"、"润色这篇论文"),系统自动匹配并调用对应专业工作流。

我的代码和数据安全吗?

HyperCode 全部本地运行,代码与文档不上传云端。API 调用直连模型服务商,key 只存在你自己的环境变量里。
