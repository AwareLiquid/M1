Architecture

Brain-Inspired Neural Foundation

MT-LNN is a continuous-time recurrent architecture extended with a stack of neuroscience-inspired "liquid core" modules for awareness, memory, and plasticity.

Liquid Time-Constant Core

Hidden state evolves according to learnable time constants — not discrete layer stacking. Continuous-time dynamics enable richer temporal representation at every scale.

Neuroscience Modules

Competitive Global Workspace (GWT-B), predictive world model, Hebbian plasticity, predictive coding, and rhythm modulation — inspired by mammalian cortical circuits.

Elastic Weight Consolidation

Fisher-weighted quadratic penalty anchors weights critical to prior domains, enabling the model to sequentially learn new tasks without overwriting old knowledge.
