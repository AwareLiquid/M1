Bio-inspired Architecture

Three Mechanisms That Make Thinking Possible

AwareLiquid stacks three neuroscience-derived subsystems on a continuous-time liquid core — each solving a distinct cognitive problem that Transformers and SSMs cannot address.

M1 · M-Series

Global Workspace Theory (GWT)

Specialist cortical modules compete for a shared broadcast channel — the "global workspace." The winner propagates its representation to all other modules, enabling selective attention, emergent integration, and conscious-like information routing.

M1 · M-Series

Sleep Consolidation (NREM Bridge)

Synthetic NREM cycles replay short-term session activations and compress them into a persistent graph-memory structure. Synaptic Homeostasis (SHY) downscaling prunes redundant connections, boosting signal-to-noise. The model grows smarter during rest.

O1 · O-Series

Liquid ODE Dynamics

Hidden state evolves as a continuous-time differential equation with learnable time constants — inspired by microtubule dynamics. No discrete layer stacking, no KV-cache growth. Constant-memory state enables edge deployment at millisecond latency.

Where it fits

Built for streams that never stop, on hardware that cannot grow.

A fixed-size carried state and tolerance for irregular sampling are what these deployments have in common. Each tile states exactly what we have measured and what we have not.

Battery management

State-of-health regression on cell voltage, current and temperature streams, running on the pack controller rather than in the cloud.

Measured — NASA PCoE cells +7.7% degradation at 80% sample loss, vs +31.1% LSTM / +32.8% GRU. 2.6 KB streaming state vs 34 MB KV-cache at 32K.

In-vehicle systems

Long-running cabin and telemetry context on an automotive SoC, where a KV-cache that grows with the drive is not an option.

Target application No pilot data yet. Architectural fit: bounded memory across an unbounded session; event-driven, non-uniform sensor sampling.

On-device assistants

Phone-resident models that keep multi-day conversational context inside a fixed RAM budget instead of truncating history.

Target application No pilot data yet. Architectural fit: constant carried state; cross-session snapshot and restore is bit-exact.

Hearables

Always-on audio and biosignal processing under a milliwatt power envelope, where duty-cycling makes the input stream irregular by design.

Target application No pilot data yet. Architectural fit: continuous-time dynamics accept non-uniform Δt natively, without resampling.

Financial time series

Irregularly-spaced tick and event data, where the gaps between observations carry as much signal as the observations.

Target application No pilot data yet. Architectural fit: Δt is an input, not an assumption — no forced regridding of an uneven series.

Industrial robotics

Closed-loop control and condition monitoring on embedded controllers with a hard, fixed memory ceiling.

Target application No pilot data yet. Architectural fit: deterministic per-step cost and a state that does not grow with uptime.
